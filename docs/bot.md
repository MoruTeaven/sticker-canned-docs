# 爬虫声明 · MoruTeaven-bot/0.1

表情罐头（[sticker.moruteaven.com](https://sticker.moruteaven.com/)）是一个表情图片**索引**服务：仅提供搜索、预览缩略图与来源链接，**原图始终保存在源站**，点击结果将跳转至源站原页面，版权归源站 / 原作者所有。为建立这份索引，我们使用一个自有爬虫按下面的规则访问互联网。

| 联系 | `me@MoruTeaven.com` |

## 礼貌参数

- 同域请求间隔 **≥ 1.5s**
- 全局并发 **≤ 2**
- 默认限速 **1Mbps**
- **夜间调度为主**，尽量避开源站白天高峰

## 索引纪律

- 只收录**表情 / 图集 / 动漫 / 娱乐**类目页面
- **不收录时政与社会新闻页面**
- 本站仅存储**搜索用缩略图与元数据**；原图始终保存在源站

## 站点边界与退出机制

本服务只提供索引与链接，不构成任何内容授权。权利人如不希望自己的内容被收录、或希望降低抓取频率，可发邮件至 `me@MoruTeaven.com`：

- **要求降频 / 整站退出索引均可，收到即执行**
- 版权投诉同样经此邮箱，附图片直链与权属说明，收到后即从索引断开相关条目

爬虫访问第三方源站时，遵守该站点自己的 `robots.txt`；[本站 robots.txt](/robots.txt) 则是表情罐头文档站对来访爬虫（含搜索引擎）的声明。如果你在日志里看到 `MoruTeaven-bot/0.1`，可据此判断来源；如需核验，请以上述联系方式与我们沟通。
